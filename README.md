# One & Only Store — сайт регистрации браслетов

## Возможности
- Адаптивный сайт в стиле One & Only Store.
- Регистрация номера браслета: один номер можно зарегистрировать только один раз.
- Сохранение заявок в SQLite.
- Админ-панель `/admin`, просмотр и удаление регистраций.
- Уведомление владельца в Telegram о каждой новой регистрации (если указать настройки бота).
- Поля отправителя и получателя, телефон, доставка СДЭК и комментарий.

## 1. Запуск локально

Требуется Python 3.11 или новее.

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

macOS/Linux:
```bash
source venv/bin/activate
```

Установка и запуск:
```bash
pip install -r requirements.txt
python app.py
```

Открой `http://127.0.0.1:5000`. Админка: `http://127.0.0.1:5000/admin`.

## 2. Подключение уведомлений в Telegram

1. В Telegram открой **@BotFather**.
2. Отправь `/newbot` и следуй инструкциям.
3. Сохрани токен бота в секрете. Не отправляй его посторонним и не публикуй в коде.
4. Открой своего нового бота и нажми **Start**.
5. Узнай свой Telegram Chat ID: можно написать боту `@userinfobot` и посмотреть свой ID. Если уведомления должны приходить в группу, добавь туда своего бота и используй ID группы.
6. Задай переменные окружения перед запуском:

Windows PowerShell:
```powershell
$env:TELEGRAM_BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
$env:TELEGRAM_CHAT_ID="ТВОЙ_CHAT_ID"
$env:ADMIN_PASSWORD="НАДЁЖНЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ"
$env:SECRET_KEY="ДЛИННАЯ_СЛУЧАЙНАЯ_СТРОКА"
python app.py
```

macOS/Linux:
```bash
export TELEGRAM_BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
export TELEGRAM_CHAT_ID="ТВОЙ_CHAT_ID"
export ADMIN_PASSWORD="НАДЁЖНЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ"
export SECRET_KEY="ДЛИННАЯ_СЛУЧАЙНАЯ_СТРОКА"
python app.py
```

После этого каждая успешная регистрация отправит тебе сообщение в Telegram. Если настройки Telegram не заданы, регистрация всё равно сохранится на сайте, но уведомление не отправится.

## 3. Публикация в интернете

Сам сайт пока не размещён в интернете — для публичной ссылки нужен аккаунт на хостинге и настройки развертывания.

1. Загрузи папку проекта в свой GitHub-репозиторий.
2. Создай на выбранном Python-хостинге веб-сервис из репозитория.
3. Команда установки: `pip install -r requirements.txt`
4. Команда запуска: `gunicorn app:app` (добавь `gunicorn` в `requirements.txt`, если хостинг требует эту команду).
5. В панели хостинга добавь переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ADMIN_PASSWORD`, `SECRET_KEY`.
6. Для сохранения регистраций после перезапуска настрой постоянный диск/том и укажи базу на нём. Обычная временная файловая система некоторых хостингов может очищаться при новом развертывании.

## Важно перед запуском для покупателей
- Поменяй пароль админки и `SECRET_KEY`.
- Убедись, что у хостинга настроен HTTPS и постоянное хранение базы.
- В форме есть отметка согласия, но для реального магазина добавь ссылку на полноценную политику обработки персональных данных и проверь требования закона, применимого к твоим покупателям.
- Даты рождения и телефоны — персональные данные. Не публикуй базу и не пересылай токен бота посторонним.
- Для коммерческого запуска рекомендуется добавить CSRF-защиту, ограничение частоты запросов и резервное копирование базы.


## Render: самый простой вариант с постоянной SQLite-базой

В проект уже добавлен `render.yaml`: база будет храниться в `/var/data/store.db`, а Render persistent disk смонтирован в `/var/data`.

1. Создай GitHub repository и загрузи в него содержимое архива (не сам ZIP внутри другого ZIP).
2. В Render: New → Web Service → подключи GitHub repository.
3. Можно выбрать конфигурацию из `render.yaml` или задать:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
4. Выбери платный Web Service, потому что persistent disk доступен на платных Web Services.
5. Disk: Mount Path `/var/data`, Size `1 GB`.
6. Environment Variables:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `TELEGRAM_CHAT_ID` — твой Chat ID
   - `ADMIN_PASSWORD` — новый сложный пароль
   - `SECRET_KEY` — длинная случайная строка
   - `DATA_DIR` — `/var/data`
7. После Deploy открой выданный Render URL.

Render поддерживает автоматические деплои из GitHub и запускает Flask с Gunicorn. Persistent Disk сохраняет изменения файловой системы между деплоями и перезапусками; для этого проекта SQLite хранится на `/var/data`.
